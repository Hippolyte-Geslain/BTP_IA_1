## 📖 Getting Started

### Prerequisites
- Node.js 18+
- MongoDB (local or MongoDB Atlas)
- VS Code (recommended)

### Installation Steps

1. **Create project directory**:
   ```bash
   mkdir plateforme-xp
   cd plateforme-xp
   ```

2. **Copy all code** from the 5 PART files to their respective locations

3. **Copy configuration files** from this directory to project root

4. **Install dependencies**:
   ```bash
   npm install
   ```

5. **Configure environment**:
   ```bash
   cp .env.local.example .env.local
   # Edit .env.local with your MongoDB URI and JWT secret
   ```

6. **Run development server**:
   ```bash
   npm run dev
   ```

7. **Open browser**:
   ```
   http://localhost:3000
   ```
