## ❓ QUESTIONS FRÉQUENTES

### Q: "Combien de temps ça prend vraiment?"
```
A: Budget réaliste:
- Phase 1 (Backend): 2-3 semaines
- Phase 2 (Frontend): 3-4 semaines
- Phase 3 (Déploiement): 1-2 semaines
- Total MVP: 6-9 semaines (1.5-2 mois)

Mais il faut compter:
- Apprentissage nouveau (React, etc): +1 mois
- Bugs imprévisibles: +1 semaine
- Produits real: 3-4 mois
```

### Q: "Quel niveau de programmer faut-il?"
```
A: Au moins:
- Python intermédiaire ✅ (vous l'avez)
- Concepts OOP ✅ (vous les avez)
- HTML/CSS basique (vous l'apprendrez)
- JavaScript basique (vous l'apprendrez)

→ Vous pouvez 100% le faire!
```

### Q: "Par quoi je commence cette semaine?"
```
A: En order:
1. Lire AVANT_APRES.md + ROADMAP_RAPIDE.md (1h)
2. Installer les outils: Python, Node, PostgreSQL (1h)
3. Créer le premier endpoint Flask (2h)
4. Tester avec Postman (1h)

Total: 5h → Vous avez une API!
```

### Q: "Ça va casser mon app actuelle?"
```
A: Non! 
- Votre code actuel (app_gui.py) reste intact
- Vous créez un nouveau dossier 'backend'
- Vous créez un nouveau dossier 'frontend'
- Votre app_gui.py continue de marcher
```

### Q: "Est-ce vraiment gratuit?"
```
A: Pour développer: OUI! 100% gratuit
- Python: Gratuit
- Flask: Gratuit
- PostgreSQL: Gratuit (ou SQLite)
- React: Gratuit
- VS Code: Gratuit
- GitHub: Gratuit (repos publics)

Pour lancer en production:
- Petit: $5-20/mois (Heroku, Railway)
- Moyen: $50-100/mois (AWS, DigitalOcean)
- Gros: $500+/mois
```

### Q: "Quelle est la meilleure BD pour commencer?"
```
A: Options:
1. SQLite (✅ Recommandé pour MVP)
   - Zéro setup
   - Facile à tester
   - Gratuit
   - Upgrade vers PostgreSQL après

2. PostgreSQL
   - Professional
   - Plus compliqué à setup
   - Meilleur pour production

→ Commencez avec SQLite!
```

### Q: "Je dois apprendre TypeScript?"
```
A: Non, c'est optionnel.
- Commencez avec JavaScript
- Passez à TypeScript après MVP
- TypeScript = JavaScript + Types
- Vous apprendrez quand vous serez prêt
```
