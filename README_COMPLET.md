## 📖 GUIDE D'UTILISATION

### 1️⃣ Première connexion
1. Lancez `NETTOYER_ET_RELANCER.bat`
2. Entrez votre **nom complet**
3. Entrez votre **email**
4. Sélectionnez votre **année** (B1, B2, B3)
5. Cliquez sur **"Créer un compte"**

### 2️⃣ Navigation
- Utilisez le **menu latéral gauche**
- Cliquez sur une section pour l'ouvrir
- Toutes les sections sont **entièrement fonctionnelles**

### 3️⃣ Gagner de l'XP
- **Complétez des projets**
- **Participez au chat**
- **Partagez des ressources**
- **Aidez les autres**
- **Rejoignez des tournois**

## 🐛 RÉSOLUTION DE PROBLÈMES

### ❌ L'application ne se lance pas
1. Vérifiez Python : `python --version`
2. Installez CustomTkinter : `pip install customtkinter`
3. Relancez : `python app_moderne.py`

### ❌ Erreur de données
1. Fermez l'application
2. Supprimez `plateforme_data.json`
3. Relancez l'application

### ❌ Erreur de création de compte
1. Vérifiez que tous les champs sont remplis
2. Utilisez un email unique
3. Relancez si nécessaire
